# Скрипты для тестирования

## create_test_teams.py

Скрипт для автоматического создания 20 команд и подтверждения всех участников.

### Использование

```bash
# Из корневой директории проекта
python scripts/create_test_teams.py

# Или через Docker
docker exec -it hackathontyuiu-hackathon-1 python scripts/create_test_teams.py
```

### Что делает скрипт:

1. **Создает 20 команд** для активного события
2. **Создает пользователей**:
   - 20 тимлидов (teamlead1@test.com - teamlead20@test.com)
   - 80 участников (member1_1@test.com - member20_4@test.com)
   - 5 наставников (mentor1@test.com - mentor5@test.com) - распределяются между командами
3. **Все пользователи**:
   - Имеют статус `approved` (одобрены)
   - Email верифицирован
   - Имеют роль `participant` (для участников) или `mentor` (для наставников)
   - Имеют полную информацию (ParticipantInfo или MentorInfo)
4. **Все команды**:
   - Имеют статус `active` (тимлид + 4 участника + наставник, все одобрены)
   - Привязаны к активному событию
   - Имеют название и девиз

### Пароли

Все пользователи имеют пароль: `password123`

### Структура команд

- **Тимлид**: teamlead{N}@test.com (роль teamlead в команде)
- **Участники**: member{N}_{1-4}@test.com (роль member в команде)
- **Наставник**: mentor{1-5}@test.com (роль mentor в команде, может быть в нескольких командах)

### Примечания

- Скрипт проверяет существование пользователей перед созданием (не создает дубликаты)
- Наставники распределяются между командами (5 наставников на 20 команд)
- Все команды создаются для активного события
- Все участники имеют статус `approved` и сразу могут участвовать
